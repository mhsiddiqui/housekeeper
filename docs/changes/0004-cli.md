# 0004: `housekeeper sources` and `housekeeper list`

- **Date:** 2026-11-23
- **Branch / PR:** committed directly to `main`
- **Plan chunks:** 1.7
- **Commits:** `5cc41ea`

## What changed
- New crate `housekeeper-cli` with the `housekeeper` binary.
- `sources`: probes every source and shows availability and version (`--json`).
- `list`: parallel scan; by default only items installed on purpose; `--all`, `--source`, `--search`, `--json`
  (the versioned scan document, schema 1).
- Source failures are printed as warnings; a closed pipe (`housekeeper list | head`) exits quietly.
- Non-Linux builds compile and say only Linux is supported.

## Why
A usable front end for the inventory, and the JSON contract the desktop app and SSH support will use later.

## How it was verified
4 unit tests (default filter, search, table alignment, sizes). Real runs of every command on Ubuntu 26.04, including
`| head` and an unknown `--source`.

## Known limits and follow-ups
- The table does not show which Node version (or other origin) an item belongs to; `--json` does.
